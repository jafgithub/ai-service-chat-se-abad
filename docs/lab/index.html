Every question asked of any of the three assistants leaves a trail: what it understood, what it looked up, which engine wrote the answer, and how long each of those actually took. This page draws that trail as it happens. The one thing worth watching is the engine. When our own hardware answers you will see it go there. When it cannot, you will see it diverted, and you will be told why.

Live: real requests, real milliseconds, nothing invented. Thin when nobody is using the system, which is honest rather than a fault.

          Gpu cards

          A card does not answer one question at a time. It answers a batch each pass, so throughput rises with batch size and so does the wait. Autoscale is on: a burst buys a card and then gives it back.
